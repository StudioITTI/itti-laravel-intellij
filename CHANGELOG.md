# itti-laravel-intellij Changelog

## [Unreleased]

## [0.1.0] - 2026-11-23

### Added

- Translation keys in schema YAML, PHP `*Key` arrays and `t()` calls: navigation per segment and locale, completion, unknown / missing-locale warnings, an Alt+Enter fix that adds the key
- Field names and `rel:` paths in Model/List/EditSchema YAML, resolved through relations to columns, schema fields and accessors
- Slots, `list:`, `tabTitle` and repeater checks in schema layouts
- Config registries: navigation routes, Blade views and partials, block layouts, `html-preset`, mail templates and placeholders, `#[Restricted]` permissions
- `mdi-…` icons with gutter previews and completion
- Gutter navigation across a domain's model, controller, schemas, pages and route
- Find usages and rename from relations, accessors, lang keys, columns, placeholders, schema keys and slots
